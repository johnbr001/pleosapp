## 범위와 확인일

공식 공고·제조사 발표·개발사 제품 설명과 도움말을 근거로 정리했습니다. 출처와 확인일은 각 문서에 표시했습니다. 기존 Apple·Google 앱 기능 설명은 2026년 10월 27일 확인분이며, 새 공모전·플랫폼·주요 앱 조사는 2026년 11월 9일 확인분을 반영했습니다.

앱 수는 발표 시점·국가·차종별 범위를 구분했습니다. 자동차 앱 98개 항목은 여러 플랫폼에 중복 등장하는 서비스를 포함하며, 고유 앱 수 또는 인기 순위가 아닙니다. 주요 앱 상세 설명 48개는 기존 목록 66개 항목과 연결됩니다. 모바일 일반 제품 기능과 차량용 버전에서 확인된 기능을 구분했으며, 실차 실행을 직접 검증한 자료는 아닙니다.

공모전 적용 아이디어나 출품 추천은 포함하지 않았습니다.
